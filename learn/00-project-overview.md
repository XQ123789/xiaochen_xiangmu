# 00 - 项目总览

## 一、项目背景与目标

本项目是一个**基于 STM32F103ZET6 的 GPS 实时定位追踪系统**，以智能小车为载体，融合了 4G 通信、传感器采集、云端数据展示和远程控制等功能。

**核心目标：**
- 实时采集 GPS 定位数据（经纬度、海拔、速度、方向）
- 采集环境温湿度（DHT11 传感器）
- 通过 4G 网络将数据上传至 OneNet 云平台
- 树莓派 + Web 前端展示实时位置与路径规划
- ESP8266 控制智能锁箱（远程开关门）

> 项目初期使用阿里云，后因收费问题迁移至中国移动 OneNet 云平台。坐标系统从百度地图切换为高德地图（GCJ02 坐标系）。

---

## 二、三层架构详解

### 第一层：底层（执行层）
- **电机控制小车**：驱动小车前往指定坐标，结合雷达、超声波实现运动与避障
- **智能锁箱**：ESP8266 + 继电器实现无线开关门控制，只要有网络即可远程控制
- 锁箱支持密码或二维码解锁，可在起点/终点自动开关，也可中途手动中断

### 第二层：传输层（通信层）
- **BC20/EC200U-CN 4G 模块**：通过 AT 指令与 STM32 串口通信
- **GPS 定位**：模块内置 GPS，通过 `AT+QGPSLOC=2` 获取 NMEA 格式定位数据
- **MQTT 协议**：数据通过 MQTT 上传至 OneNet 云平台（`mqtts.heclouds.com:1883`）
- **坐标转换**：WGS84（GPS 原始坐标）→ GCJ02（高德地图坐标系）

### 第三层：显示层（应用层）
- **树莓派**：前期使用 Zero 2 W（调试），后期使用 4B（多功能汇总）
- **Web 前端**：展示实时位置、路径规划、路况摄像头画面
- **路径规划**：预先规划路径坐标，树莓派获取当前 GCJ02 坐标后与规划坐标比较（5m 误差容限），逐步下发下一个目标点
- **人工干预**：支持突发问题时的人工操作（远期规划）

## 四、硬件清单

| 硬件 | 型号 | 作用 |
|------|------|------|
| 主控 MCU | STM32F103ZET6 | 核心控制器，协调各模块 |
| 4G 模块 | BC20 / EC200U-CN | GPS 定位 + 4G 网络数据传输 |
| 温湿度传感器 | DHT11 | 采集环境温度与湿度 |
| WiFi 模块 | ESP8266 | 智能锁箱无线控制 |
| 继电器 | 5V 继电器模块 | 锁箱开关门执行机构 |
| 显示/计算 | 树莓派 Zero 2W / 4B | 路径规划、Web 服务 |
| 电机驱动 | 直流电机 + 驱动板 | 小车运动控制 |
| SIM 卡 | 中国移动 4G SIM | 4G 网络接入 |
