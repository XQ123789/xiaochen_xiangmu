## 知识要点

- **AT指令基本格式**：`AT+指令名=参数\r\n`，成功响应包含`OK`，失败响应`ERROR`
- **初始化AT指令序列**（CSTX_4G_Init）：
  1. `ATE1` → 开启回显，测试与模块通信
  2. `ATI` → 查询模块型号信息
  3. `AT+CIMI` → 读取SIM卡IMSI号（"460"开头=中国移动）
  4. `AT+CGATT?` → 查询网络附着状态（`+CGATT: 1`=已注册）
  5. `AT+CSQ` → 查询信号质量（返回值0-31，越大越好）
  6. `AT+QGPS=1` → 开启GPS模块
  7. `AT+QGPS?` → 轮询GPS定位状态（最多重试10次）
- **重试机制**：每个AT指令都有while循环等待响应，直到成功
- **已知问题**：所有while循环无超时退出，模块无响应时永久卡死
