## 知识要点

- **三层架构**：
  - 第一层（执行层）：电机控制小车 + ESP8266智能锁箱
  - 第二层（传输层）：BC20 4G模块 + GPS定位 + MQTT上传
  - 第三层（应用层）：树莓派路径规划 + Web前端展示
- **核心数据流**：GPS模块 → STM32 → 4G模块 → OneNet云平台 → Web前端
- **坐标系统**：GPS原始坐标是WGS84，高德地图需要GCJ02，需要转换
- **硬件清单**：STM32F103ZET6、BC20/EC200U-CN、DHT11、ESP8266、树莓派
