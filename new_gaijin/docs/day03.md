## 知识要点

- **缓冲区结构**：
  ```c
  typedef struct {
      uint8_t buf[BUFLEN];  // 数据缓冲（BUFLEN=256）
      uint16_t index;        // 当前写入位置
  } Buffer_TypeDef;
  ```
- **中断接收流程**：
  1. 硬件收到1字节 → 触发USART中断
  2. 中断服务函数读取数据 → 存入 `buf[index]`
  3. `index++` → 准备接收下一个字节
  4. 当 `index >= BUFLEN` 时 → 重置为0（溢出处理）
- **三路串口**：
  - `buf_uart1`：调试输出
  - `buf_uart2`：BC20 4G模块数据（AT指令响应）
  - `buf_uart3`：树莓派通信数据
- **已知问题**：溢出时静默重置index，丢弃数据无告警（改进版待解决）
