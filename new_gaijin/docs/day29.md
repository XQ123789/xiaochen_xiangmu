## 知识要点

- **回退验证**（开关定义在 `new_gaijin/include/ng_config.h`，共 8 个独立 `USE_NEW_*` 开关）：
  1. 全部 `USE_NEW_*` 设 0 → 编译原版代码
  2. 烧录到STM32 → 验证系统正常运行
  3. 7 个 `USE_NEW_*` 设 1（`USE_NEW_APP` 保持 0）→ 编译new_gaijin代码
  4. 烧录到STM32 → 验证系统正常运行
  5. 两种模式都能正常工作 = 回退机制有效
  6. 进阶：只关掉某一个开关（如 `USE_NEW_COORD=0`）再编译烧录，验证单模块可独立回退
- **边界测试场景**：
  - GPS模块断开：拔掉GPS天线，观察系统行为
  - 4G信号丢失：遮挡4G天线，观察重连机制
  - DHT11故障：断开DHT11，观察错误处理
  - 电源波动：用不稳定电源，观察看门狗复位
- **异常注入测试**：
  - 模拟GPS响应为"ERROR"：验证解析器处理
  - 模拟MQTT发送失败：验证重连机制
  - 模拟缓冲区溢出：验证保护机制
- **测试记录**：
  - 每个测试场景的预期结果
  - 实际结果
  - 偏差分析
