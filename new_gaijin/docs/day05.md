## 知识要点

- **单总线协议**：只用一根数据线（DHT11 DATA引脚接PA11），通过时序区分0和1
- **GPIO模式切换**：
  - 推挽输出（`DHT11_Mode_Out_PP`）：主机发送起始信号
  - 上拉输入（`DHT11_Mode_IPU`）：主机接收DHT11响应和数据
- **读取流程**：
  1. 主机拉低数据线18ms（起始信号）
  2. 主机拉高30us
  3. 切换为输入模式
  4. DHT11拉低80us → 拉高80us（响应信号）
  5. 逐位读取40位数据（湿度整数+湿度小数+温度整数+温度小数+校验和）
- **数据位判定**：高电平持续26-28us=0，高电平持续70us=1
- **数据结构**：
  ```c
  typedef struct {
      uint8_t humi_int;    // 湿度整数
      uint8_t humi_deci;   // 湿度小数
      uint8_t temp_int;    // 温度整数
      uint8_t temp_deci;   // 温度小数
      uint8_t check_sum;   // 校验和
  } DHT11_Data_TypeDef;
  ```
