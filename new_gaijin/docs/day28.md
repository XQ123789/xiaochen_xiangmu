## 知识要点

- **端到端测试流程**：
  1. 系统上电 → 初始化所有模块
  2. 4G模块注册网络 → MQTT连接OneNET
  3. GPS模块定位 → 获取WGS84坐标
  4. ng_coord转换 → GCJ02坐标
  5. ng_json_builder构建 → JSON数据
  6. ng_mqtt_wrapper发送 → OneNET接收
  7. Web前端显示 → 验证数据正确
- **测试检查点**：
  - 编译是否成功（无错误、无警告）
  - 烧录后系统是否正常启动
  - LED状态指示是否正确
  - GPS数据是否正常读取
  - 坐标转换结果是否合理
  - MQTT连接是否成功
  - OneNET是否收到数据
  - Web前端显示是否正确
- **常见问题排查**：
  - 编译错误：检查头文件包含路径
  - GPS无数据：检查天线连接，到室外测试
  - MQTT连接失败：检查SIM卡和信号
  - 数据偏差大：检查坐标转换是否正确
