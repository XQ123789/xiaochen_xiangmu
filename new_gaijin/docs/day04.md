## 知识要点

- **看门狗(IWDG)作用**：程序跑飞时自动复位系统，防止死机
- **初始化参数**：`IWDG_Init(6, 500)` — 预分频64，重装值500，超时约4秒
- **喂狗操作**：`IWDG_ReloadCounter()` — 告诉系统"程序还在正常运行"
- **不喂狗后果**：超时后系统自动复位
- **GPIO操作**：
  - `GPIO_SetBits()` → 输出高电平（LED灭，因为LED负极接GPIO）
  - `GPIO_ResetBits()` → 输出低电平（LED亮）
- **4G开机时序**：PA12先高1秒 → 拉低 → 触发4G模块开机
